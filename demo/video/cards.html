Built on Relate by Neo4j

Pull requests for agent memory.

memory-pr reviews every change to what your agents know, as a graph.

The problem

Agents share what they learn as Markdown notes in git.

Git says a merge is clean. The graph is damaged.

Two facts contradict. A fact rests on one that was replaced. No text diff shows it.

Why Relate

The Markdown folder is the database.

Git gives the graph review and history. Every rule is a Cypher query over the merged graph.

The same rules run in CI and in the browser, where Relate is compiled to WebAssembly.
