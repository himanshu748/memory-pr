# Data and dependencies

The sample project and scripted demo agents are fictional. The real-repository
scan reads public files on request. The backend does not retain the scan, set
cookies, or require an account.

Relate is used through `relate-db` and `@relate/relate-wasm`. Other
dependencies include PyYAML, the MCP Python SDK, Cytoscape.js, the Geist and
Geist Mono fonts, pytest, and Ruff. See [vendored licenses](../site/vendor/README.md).

Built with AI assistance (Devin).
